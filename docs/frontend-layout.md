# 前端排版合同

**适用对象：** 首页、书籍详情页和响应式布局维护者。

## 七字宽书名

`src/lib/bookTitleLayout.ts` 只判断主标题是否少于七个 Unicode 字符，不决定具体
像素宽度。首页和详情页复用这一判断，但各自按照实际字体字面设置宽度：

- 首页使用普通锦书宋，汉字进宽为 `1em`，短标题铺满 `7em`；
- 详情页使用扁字形锦书宋，汉字进宽为 `0.75em`，短标题铺满 `5.25em`；
- 七字及以上标题保持自然排版，不强制压缩；
- 单字标题在对应七字宽区域内居中；
- 不使用 `letter-spacing` 模拟分布，避免把字距叠加到字形宽度上。

首页和详情页不得共享固定的 `7em` 或 `5.25em` 数值。更换字体时应先读取字体实际
advance width，再分别调整视图样式；不能根据视觉印象假定字体是全角或扁字形。

## 简讯分段符

置顶消息和普通消息同时存在时，简讯栏显示三个全角星号 `＊`。分段符宽度始终为
消息内容 frame 的 `100%`，内部使用三列等分网格，每个星号在本列居中。三个中心
相对于 frame 左侧的位置应分别为 `1/6`、`1/2`、`5/6`。

不得通过固定像素宽度、左右 padding 或手工空格排列星号。frame 在响应式布局中变化
时，分段符必须同步伸缩。

## 上架书目

首页书架左侧的“上架书目”标牌是 `/books/` 的入口；其下方“索引”按钮仍进入
`/categories/`，两者不得合并为同一路由：

- `/books/` 复用索引页的封面网格，展示全部当前上架书目；
- 所有保留页面复用报纸式面包屑页头；旧版固定全局导航及其 `Layout.astro` 已删除，
  不得重新用于新页面；
- 上架书目页不重复显示大标题，当前页面名称只在面包屑中出现；
- 排序依据为第一版 manifest 的 `generatedAt`，缺失时回退第一版发行日期；
- 首页新书速递仍按最新版更新时间选择首书，不受上架时间排序影响；
- 相同上架时间使用书号排序，保证静态构建结果稳定。

## 固定字位与链接下划线

“新书速递”不得用 `writing-mode` 配合 `letter-spacing` 排列。字距会叠加在字体自身的
字形进宽上，系统字体或字体加载阶段不同便会产生跨设备差异。当前实现把四个字符拆为
四个固定 `24px` 字位，以 `8px` 行距排列，并禁止浏览器合成字重。

普通文本链接由 `global.css` 统一声明完整下划线属性；简讯列表的可打开消息是原生
`button`，因此单独复用同一视觉参数：

- `text-decoration-line: underline`；
- `text-decoration-style: solid`；
- `text-decoration-thickness: 1px`；
- `text-decoration-skip-ink: none`；
- `text-underline-position: under`。

可打开消息使用原生 `button` 时，还必须清除 `appearance` 与 `-webkit-appearance`，避免
iOS WebKit 的按钮外观可能覆盖文字装饰。不要只使用 `text-decoration: underline` 简写。
图片入口、命令按钮和面包屑导航可显式取消下划线；普通正文、公告和页脚链接不得另写
一套装饰规则。链接在 hover 与键盘 focus 时统一切换为主题红色。

Heti 会在西文与中文边界插入间距节点，浏览器原生下划线会在该节点处断开。对于不会
换行的短链接（当前为“ntfy备用信号源”），使用同一 `1px` 变量绘制连续底边，并保留
Heti 的中西文间距；不得通过删除间距或手工添加空格规避断线。

## 搜索、系列名与目录大纲

索引页的关键词输入内容不可使用字体子集。用户可能输入书库尚未收录的任意汉字，搜索框
必须直接使用 `--font-system-songti` 系统宋体栈；不得回退到随书目内容裁剪的展示字体。

无系列名的详情页在桌面端保留隐藏行，以维持不同书籍之间的标题基线。紧凑视口下不需要
这项横向对照，`.bd-series--empty` 必须完全折叠，不给主标题保留空白位置；有系列名时仍
正常显示。

目录 JSON 保留 PDF 书签原文。详情页调用 `normalizeOutlinePunctuation()` 统一显示为半角
标点，包括全角 ASCII、中文句读、括号、引号和书名号；不得直接批量改写书签派生文件，
以免影响版本差异和入库审计。

## 响应式验收

至少检查以下视口：

- 桌面：`1440 × 900`
- 横向平板：`1024 × 768`
- 竖向手机：`390 × 844`
- 窄屏保护：`320 × 568`

等待 `document.fonts.ready` 后再测量文字。短标题应使用对应视图的字体与七字宽；
简讯分段符应与内容 frame 同宽；页面不得出现横向溢出。打开带正文的简讯后再返回，
列表位置、原触发按钮和布局宽度应恢复。

代码修改后运行：

```bash
mise exec -- npm run test:ui
mise exec -- npm run check
mise exec -- npm run build
```

合并前仍以 `mise exec -- npm run verify` 为完整验证入口。
